# Meenz City 🏰🚗

GTA-artiges Open-World-Browserspiel in **Mainz und Wiesbaden** – gebaut mit three.js aus OpenStreetMap-Daten.
Jetpack, Marktfrühstück, Fliegerdackel, Flugplatz Großer Sand, Jetskis, Gokart-Rennen, UFOs und viel Meenzerisch.

- Spielen: `game/meenz-city.html` im Browser öffnen (oder das claude.ai-Artifact).
- Bauen & Testen: siehe [CLAUDE.md](CLAUDE.md).

Kartendaten © OpenStreetMap-Mitwirkende, ODbL.
